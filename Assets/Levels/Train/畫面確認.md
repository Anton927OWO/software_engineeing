# 確認精簡後的知識列車畫面

## 開啟正確專案

1. 在 Unity Hub 開啟 `/Users/testarossa/Desktop/new-unity-mid`，使用 **Unity 6000.3.19f1**。
2. 專案的 Git 分支應為 **codex/team-train**。可在此資料夾執行 `git branch --show-current` 確認。
3. 在 Project 視窗搜尋 `L_Train`，雙擊 `Assets/Levels/Train/L_Train.unity`。
4. 切到 **Game** 分頁，選 **16:9** 或 **1920×1080**，按上方 **Play**，再按介紹中的「開始探索」。

直接開 Train Scene 可確保看到本次畫面；若從 Boot 開始完整流程，隨機抽關不一定會抽到知識列車。

## 畫面應該長這樣

- 上方保留「知識列車」、倒數與暫停。
- 同一張題卡內依序是主題、題目、三個左對齊選項，以及答題後的一句原因。
- 右上「解說／來源」可展開完整解釋、官方網址與查核日期；開啟時倒數暫停。
- 主畫面不再顯示四散的操作提示、重複目標、來源日期、狀態文字與數字車廂進度。
- 每答對一題仍接上一節車廂，車廂只顯示站名；第五節接完並出站後才成功。

[實際答題截圖](Verification/TextFocus/question.png)、[答錯原因](Verification/TextFocus/wrong-answer.png)、[五節出站](Verification/TextFocus/five-carriages.png)、[完整來源卡](Verification/TextFocus/knowledge-answer.png)。

## 簡單回歸檢查

1. 故意答錯：原因應出現在題卡內，失誤仍計入結果。
2. 答對：原車廂接車動畫與站名應正常出現。
3. 按「解說／來源」：看到官方 URL，關閉後倒數繼續。
4. 按暫停或 Escape，再選重新開始：倒數回到 60 秒、車廂清空、重新顯示介紹。
