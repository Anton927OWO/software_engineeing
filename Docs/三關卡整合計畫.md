# Team Level Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Integrate the three existing levels on the team's main with separate pushable branches.
**Architecture:** Preserve TrackingNIU APIs and existing level mechanics. Add a bridge assembly and minimal Shared lifecycle hooks. Copy only required assets, retaining existing meta GUIDs and using team TMP resources.
**Tech Stack:** Unity 6000.3.19f1, C#, Unity Test Framework, Git LFS.
**Spec:** Docs/三關卡整合說明.md

## Global Constraints
- Do not modify original workspaces, feature/* branches, team main, or push remotely.
- Preserve Assets/Common, existing team scenes, Packages, and project settings except additive Build Settings entries.
- Use team ScoreCalculator; retain actual finale pair count and artifact identity.
- No duplicate GUIDs, old machine-specific test reports, credentials, or unrelated documents.

## Review Focus
- Scene changes must preserve the GameManager callback until Continue.
- Retry after a reported result must preserve context and permit a fresh report.
- Real artifacts must map by identity, not enum ordinal assumptions.
- Loading Foundation must not create or overwrite a TrackingNIU session.
- Separately merged branches must share exactly one common foundation and preserve team scenes.
