# 關卡介面說明

《尋跡宜大：從圖書館出發》｜負責：游士霆｜2026/10/26 開工會議用

程式都在 `Assets/Common/Scripts/LevelInterface`，namespace 是 `TrackingNIU`。這個資料夾只有游士霆修改，有需要改的地方請直接跟我說。

## 每關要做的三件事

1. **Scene 裡放 `LevelTestLauncher`**，在 Inspector 選好 Level Id。直接按 Play 就會用預設設定開始，結束時在 Console 印出結果與得分。整合後不用拿掉。
2. **`Start()` 讀取開始資料**：`LevelSession.Current` 裡有關卡名稱、地點、限時、文物編號，終章另外有本局取得的文物。
3. **結束時回傳結果**：
   - 小遊戲結束 → `var score = LevelSession.Report(new LevelResult { Cleared, RemainingTime, Mistakes })`
   - 用 `score` 顯示知識卡的得分明細（`ClearBonus`、`TimeBonus`、`MistakePenalty`、`Total`）
   - 知識卡按「繼續」→ `LevelSession.Exit()`

可以直接複製 `Samples/ExampleLevel.cs` 來改，複製後記得改 class 名稱。

## 注意事項

- **分數不要在關卡裡算**，只要回報「是否通關、剩餘時間、失誤次數」。每關扣幾分已經寫在 `LevelCatalog`。
- **計時用 `Time.deltaTime`**，暫停選單把 `Time.timeScale` 設成 0 時會自動停止。
- **專案只開了新版 Input System**，舊的 `Input.GetMouseButton` 等寫法會報錯。拖曳請用 UI 的 `IBeginDragHandler` 等介面，或用 Input System。
- **不限時的關卡**（序章）`TimeLimit` 是 0，用 `HasTimeLimit` 判斷。

## GameManager 與抽關

程式在 `Assets/Common/Scripts/GameFlow`，各關不用改任何東西。

- **流程**：序章 → 圖資館樓層地圖（館內 2 關，可任意順序）→ 無圍牆博物館地圖（戶外 1 關）→ 圖資館樓層地圖（終章）→ 結算。
- **抽關**：期中是館內 4 抽 2、戶外 2 抽 1，不重複，每次「開始新的一局」都重新抽。期末在 GameManager 勾選 **Include Finals Levels**，館內就改成 5 抽 2。
- **Boot 場景**：`Assets/Scenes/Boot.unity` 是遊戲的第一個場景（Build Settings 第 0 個），裡面有 GameManager 和流程測試面板。
- **Scene 名稱**：地圖是 `Map_Library`、`Map_Campus`，結算是 `Results`。這些還沒做好之前，GameManager 會回到 Boot 場景。
- **還沒加進 Build Settings 的關卡**在編輯器裡也能從 GameManager 進入，Console 會出現黃色提醒。

### 用流程測試面板走完一局

1. 打開 `Boot` 場景，按 Play。
2. 左邊面板按「開始新的一局」。還沒有 `L_Prologue` 的話會停在面板上，Console 會顯示找不到場景。
3. 可以「進入」已經做好的關卡，或按「模擬通關」用「通關、剩一半時間、零失誤」直接記錄結果。
4. 面板會顯示目前階段、抽到的關卡、各關分數、總分、稱號與文物。按 F1 可以隱藏面板。

## 中文字型

`Assets/Common/Fonts` 有三個 TextMeshPro Font Asset，都是 Dynamic 模式，用到的字才會產生，不會缺字：

| Font Asset | 用途 |
|---|---|
| `NotoSansTC-Regular SDF` | 內文、知識卡。**新增的 TextMeshPro 預設就是這個**，不用另外設定 |
| `NotoSansTC-Bold SDF` | 標題、按鈕、計時與分數。在 Regular 上把 Font Style 設成 **B** 就會自動改用這個字重 |
| `NotoSerifTC-Black SDF` | 只用在結算畫面的總分與稱號 |

- 文字一律用 **TextMeshPro**（Hierarchy 右鍵 → UI → Text - TextMeshPro），不要用舊的 Text 元件。
- 按 Play 後 Font Asset 檔案會因為新增字形而變動，這是正常的；commit 前在 git 中還原這三個 `.asset` 即可，打包時會自動清除。
- 字型採用 SIL Open Font License，授權文字在 `Assets/Common/Fonts/OFL.txt`。
- 如果要重建：選單 **Tracking NIU → 建立中文字型 Font Asset**。

## 開工會議要確認的提案

程式已經照下面的提案寫好，會議上同意就不用改；不同意的話我改 `LevelCatalog` 或 `ScoreCalculator`，各關程式不用動。

| # | 問題 | 提案（目前程式的做法） |
|---|------|------------------------|
| 1 | 知識卡的得分明細從哪裡來？流程是先顯示知識卡、後回傳結果 | 回傳分成兩步：`Report()` 立刻回傳得分明細給知識卡顯示，按「繼續」再呼叫 `Exit()` |
| 2 | 每關扣分不同，介面只回傳失誤次數 | 扣分寫在 `LevelCatalog`：考古 -50、知識列車 -30，其他 -20 |
| 3 | 草澤擋鹿沒有寫失誤扣分 | 每隻鹿離開地圖算一次失誤，-20 |
| 4 | 終章的配對分要另外回傳 | `LevelResult` 加一個 `MatchedPairs` 欄位，只有終章填 |
| 5 | 關卡失敗怎麼辦？終章需要湊滿 3 件文物 | 失敗時可以按「再試一次」（`LevelSession.Retry()`）或直接繼續。直接繼續時本關 0 分，**但仍然拿到文物**，避免卡關 |
| 6 | 失敗時分數怎麼算 | 沒有基礎分和時間獎勵，失誤照扣，每關最低 0 分。終章超時則保留已配對的分數 |
| 7 | 序章不限時、不計分 | `TimeLimit` = 0，`Report()` 回傳 `IsScored = false`，序章不用顯示得分明細 |
| 8 | 哪一關給哪件文物 | 考古→金箔片、百年軌跡→木質圓形雕板、知識列車→瑪瑙珠、書海→木鏟、擋鹿→金鯉魚、地層→幾何印紋陶罐 |

## 計分規則（已寫成程式並有單元測試）

- 一般關卡：通關 +1000；時間獎勵為剩餘時間 ÷ 限時 × 500，四捨五入，只在通關時給。
- 終章：每組配對 +100，最多 600；時間獎勵最高 +500。
- 失誤扣分：每關最多扣 500，每關總分最低 0。
- 單局滿分 5600。稱號：4800 以上為宜大文化守護者，4000～4799 為噶瑪蘭文化探索達人，3200～3999 為蘭陽探索者，未滿 3200 為宜大文化新旅人。

在 Unity 的 Window → General → Test Runner → EditMode 可以執行 `ScoreCalculatorTests` 和 `LevelSessionTests`。
