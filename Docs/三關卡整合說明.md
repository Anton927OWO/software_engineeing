# 三關卡整合

基底：Anton927OWO/software_engineeing 的 main（51c1598）。來源：Unity_2D_Mid 工作目錄的 Train、Timeline、Finale 與 Shared。原專案與既有 feature/* 分支保留。

## 設計與範圍

沿用團隊的 GameManager、地圖、LevelCatalog、ScoreCalculator 與 TrackingNIU.LevelSession。Shared 負責關卡內計時、介紹、暫停與遊戲畫面；TrackingLevelBridge 負責開始資料、結果、重試與離開。三關保留原玩法。分數只使用團隊的計分系統，終章回傳實際配對組數，提示文物由本局 CollectedArtifacts 取得。

保留對方的 TextMeshPro Essential Resources，不複製重複 GUID；只帶入三關必需的圖像、音效與字型及其授權。排除舊測試 XML、截圖、.DS_Store 與無關 Word 文件，原本機檔案保持不變。

## 分支

共同基底包含 Shared、橋接程式與共用素材。codex/team-train、codex/team-timeline、codex/team-finale 各自只新增該關與所需素材；codex/team-integration 合併三關，供完整測試。所有分支以團隊 main 為祖先，可正常提出 PR。尚未推送或改動團隊 main。

## 行為

直接打開 L_Train、L_Timeline、L_Finale 可以單獨測試；從 GameManager 進入時讀取正式開始資料。完成或超時後立即 Report，結果畫面呈現團隊計分明細；按「繼續」才 Exit，讓 GameManager 接回地圖或結算。正式遊戲的重試使用團隊 Retry；單獨測試的重試在本地重置並重新開始測試 Session。

## 驗證

Unity 6000.3.19f1。先跑團隊基底 EditMode，再驗證原有三關測試與新增整合測試。重點：時間覆寫、成功與失敗回報、重試後不重複回報、部分配對、實際文物映射，以及按繼續才離開。測試輸出保存在工作目錄外，避免加入本機路徑。完整結果：EditMode 92 通過、PlayMode 37 通過，0 失敗。正式 GameManager 的進關、重試、通關、回到 Map_Library 與取得文物亦已通過。獨立審查找到的未儲存場景保護與單獨測試繼續後重試問題，均已以失敗測試重現並修正。


## 使用方式

在 Unity 開啟本整合工作目錄，可直接開啟三個 L_* 關卡測試，也可開啟團隊地圖，以流程測試面板進入已實作的關卡。其他組員的序章、考古、書海、戶外與 Results 仍維持團隊基底的狀態，本次未新增那些場景。

整合工具選單：尋跡宜大 → 整合 → 準備已存在的關卡與 Build Settings。工具在有未儲存場景時拒絕執行，請先自行儲存。重新產生關卡或共同 prefab 後可重跑此工具。

目前只建立本機分支，未推送。team 遠端指向團隊專案；原 origin 保留。Git LFS 官方工具已配置於本機 Codex 工具目錄，Git filters/hooks 使用絕對路徑；既有 Unity 範本 URP 圖示依團隊既定 .gitattributes 正規化為 LFS，圖像位元組不變。
